# 设计约定

采用 `concept.png` 的完整工作台（1487 × 1058）作为实现基准。AI 生成概念图只用于设计，不作为页面 UI。

| 项目 | 约定 |
| --- | --- |
| 页面 | 80px 白色页头、236px 白色侧栏、灰色主画布 |
| 主区域 | 左侧输入与结果纵向排列，右侧执行轨迹；列宽比例约 5:3 |
| 颜色 | 画布 #f6f8fb，面板 #fff，文字 #172b42，次要文字 #526b82，边框 #e2e8f0，主色 #147d75 |
| 字体 | Segoe UI / Microsoft YaHei / sans-serif；正文 16px，控件 14px，主标题 28px |
| 间距 | 8 / 12 / 16 / 24 / 32px；面板内边距 24px |
| 组件 | 细边框 10px 圆角面板、线性 SVG 图标、实心主按钮、描边示例按钮、平面资产表格、浅琥珀异常行 |
| 交互 | 输入、执行、取消、下载、JSON 展开、复制、资产过滤、详情、评测结果、模式切换 |
| 小屏 | 侧栏变为顶部标签，主区域单列，表格仅在自身容器内横向滚动 |

必要扩展：初始空态、加载/取消/错误状态、资产台账和评测页复用同一系统；未执行前不伪造结果。真实模型未配置时选择项禁用，配置后才可调用。真实模型模式产生的自然语言结论单独标明，结构化表格只取工具返回数据。

验收对照至少包括：页头侧栏比例、双列结构、字体层级、表格密度、异常行、轨迹轴、手机布局。记录见 `qa.md`。
